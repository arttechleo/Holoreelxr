# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project setup with WebXR support
- Hand gesture recognition system
  - Pinch gesture for scrolling and grabbing
  - Thumbs up for likes
  - Heart gesture (two hands) for saves
  - Peace sign for repost
  - ILY gesture for comments
- 3D content support (PLY, splat sequences, basic shapes)
- Floating MR HUD with reaction counters and comments
- Two-hand scale and rotation controls
- Visual feedback system (particles, platform pulses)
- Raycasting-based UI interaction
- Dwell-based button activation (350ms hover)

### Documentation
- Comprehensive README with setup and usage instructions
- CONTRIBUTING guide with development guidelines
- Project documentation and architecture notes

- Core WebXR feed viewer functionality
- Hand tracking integration

- 3D content rendering
